# MKKAPP

서버 없이 시작할 수 있는 반응형 웹앱 베이스입니다. 테스트 메모로 추가, 저장, 삭제 동작을 확인할 수 있습니다.

## 로컬 실행

저장소를 다운로드하거나 복제한 뒤 `index.html`을 Chrome 또는 Edge에서 엽니다. 브라우저의 파일 주소에서 메모 저장이 제한되면, Python이 설치된 PC에서 프로젝트 폴더를 열고 다음 명령을 실행합니다.

```powershell
py -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 [http://localhost:8000](http://localhost:8000)을 엽니다. macOS와 Linux에서는 `py`를 `python3`로 바꾸면 됩니다.

메모는 현재 브라우저의 `localStorage`에 저장됩니다. 실행 주소나 브라우저가 바뀌면 저장 공간도 달라집니다.

## 나중에 서버 연결

정적 파일을 웹 호스팅에 올리고 `app.js`의 `API_BASE_URL`에 백엔드 API 기본 주소를 입력합니다. 값이 비어 있으면 로컬 모드로 실행합니다.

| 요청 | 계약 |
| --- | --- |
| `GET /notes` | `[{ "id": "문자열", "text": "메모" }]` 응답 |
| `POST /notes` | JSON `{ "text": "메모" }`을 받아 저장하고 2xx 응답 |
| `DELETE /notes/{id}` | 해당 메모를 삭제하고 2xx 응답 |

백엔드는 위 API를 구현해야 합니다. 프런트엔드와 백엔드의 출처가 다르면 백엔드에서 프런트엔드 출처의 CORS 요청을 허용해야 합니다. 서버 모드로 전환해도 기존 브라우저 메모는 자동 이전되지 않습니다.
